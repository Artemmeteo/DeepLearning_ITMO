# DeepLearning ITMO

Материалы и домашние задания университетского курса Deep Learning.

## Ветки

- `course` — структура курса и исходные задания без решений.
- `hw1`, `hw2`, … — решения отдельных домашних заданий.
- `main` — проверенные решения.

Новую ветку задания создавайте от `course`:

```bash
git switch course
git switch -c hw2
```

Решение сдаётся через PR из ветки задания в `main`. В `main` его объединяют
после проверки. Проверенные решения из `main` и веток `hwN` в `course`
не объединяются. Новые шаблоны добавляются в `course` и при необходимости
переносятся в `main` отдельно от решений.

## Задания

- `hw1_students/` — инструкции и зависимости ДЗ1. Исходного шаблона ноутбука
  пока нет; сданное решение сохранено в ветке `hw1` по пути `hw1.ipynb`.
  До завершения проверки эта ветка сохраняет прежнюю структуру файлов.
- `hw2_students/` — исходные шаблоны вариантов CV и NLP; выбрать нужно один.

Открывайте ноутбуки из папки соответствующего задания: соседние файлы
зависимостей и относительные пути `data/`, `artifacts/` используются внутри неё.
Окружение и зависимости выбирайте отдельно для каждого задания.

Датасеты, окружения, локальные настройки IDE и папки `runs/` в Git не добавляются.
Состав `artifacts/` для сдачи определяется инструкциями конкретного задания.
